La piattaforma in sintesi

Una piattaforma. Tutto il servizio.

Gestionale comande copre l'intero ciclo di vita del servizio: dall'apertura del tavolo all'incasso, dalla cucina alla fatturazione, fino alla reportistica direzionale. Sei aree, un unico sistema.

Operatività di sala

Mappa tavoli in tempo reale, presa comande touch, banco vendita rapida e sessioni di modifica in batch per zero attese.

  • Apertura, modifica e spostamento tavoli con audit
  • Banco con sessioni multiple in parallelo
  • Interfaccia mobile per tablet e smartphone
Incassi flessibili

Conto intero, suddiviso per persone o parziale per piatti. Pagamenti contanti, POS, fattura o misti, gestiti in un unico flusso.

  • Preconti multipli sullo stesso tavolo
  • Sconti percentuali, assoluti o per preconto
  • Cassetto automatico VNE Self-Cash
Conformità fiscale IT

Fatturazione elettronica al Sistema di Interscambio, corrispettivi ADE con retry policy e annulli tracciati. Tutto a norma, tutto registrato.

  • XML SDI conforme alle specifiche AdE
  • Doppio provider corrispettivi: Mysond + Ditron RT
  • Storico completo emissioni e annulli
Stampe ESC/POS

Comande in cucina e bar, marcia tavolo, preconti e scontrini distribuiti automaticamente alle stampanti di reparto via TCP/IP.

  • Multi-stampante con instradamento per categoria
  • Ristampa one-click dal log documenti
  • Notifiche di cambio piatto automatiche
Visibilità totale

Dashboard vendite in tempo reale, statistiche per operatore, best-seller, audit log integrale di ogni operazione e ogni stampa.

  • Vendite per metodo, operatore, categoria
  • Audit log e timeline per tavolo
  • Esportazione CSV/Excel
Multi-locale

Architettura master/satellite con sincronizzazione automatica di menu, anagrafiche e immagini. Gestisci una catena come fosse un unico locale.

  • Push automatico master → satellite
  • Sync media e anagrafiche complete
  • Alert Telegram su eventi critici

Integrazione nativa con
cassa fiscale Ditron RT

Gestionale comande dialoga direttamente con i Registratori Telematici Ditron tramite un agent dedicato installato sul punto vendita. Lo scontrino fiscale viene emesso sulla cassa hardware del cliente nello stesso istante in cui l'operatore conferma il pagamento — senza più isole separate, senza più doppio inserimento.

Provider selezionabile Cloud (Mysond) o hardware (Ditron) Auto-Run Spooler Compatibile con casse esistenti
Doppio provider, scelta del cliente
  • Setting corrispettivo_provider: mysond o ditron
  • Stesso flusso operatore, due tecnologie sottostanti
  • Mantiene il provider Mysond cloud SOAP per chi lo preferisce
  • Permette di passare a Ditron senza modificare la UI
Agent Windows dedicato
  • Mini-agent .NET 8 self-contained installato sul PC del locale
  • Endpoint HTTP POST /emit-receipt sicuro
  • Modalità fiscale e non fiscale (test stampa)
  • Replica esatta del pattern Auto-Run Spooler già in produzione
Idempotenza e tracciabilità
  • Chiave di idempotenza per richiesta — zero scontrini doppi
  • Storico completo nella tabella ditron_receipts
  • Registrazione di raw command, error file e tempo di esecuzione
  • Storico unificato con Mysond nella reportistica
Compatibile con il parco installato
  • Funziona con il driver Ditron WinEcrCom 3.x standard
  • Comunica via TCP/IP con la cassa già fiscalizzata
  • Tender e reparto configurabili dal backoffice
  • Etichetta coperto personalizzabile
Perché ne abbiamo bisogno. Molti ristoranti italiani hanno già investito in una cassa fiscale hardware Ditron RT con un gestionale legacy separato. Con questa integrazione, Gestionale comande unifica il flusso ordini → cassa senza richiedere sostituzioni hardware: il personale lavora su un unico sistema, lo scontrino fiscale esce sulla cassa di sempre.

Operatività di sala

Sala, tavoli e comande

Dall'apertura del tavolo al separatore di portata, ogni gesto del cameriere è progettato per essere immediato.

01
Gestione tavoli e sala
  • Mappa interattiva dei tavoli con stato in tempo reale: libero, occupato, in pagamento
  • Apertura tavolo con scelta del numero di coperti e assegnazione del cameriere
  • Modifica coperti durante il servizio con ricalcolo automatico del coperto
  • Spostamento di un ordine da un tavolo all'altro con tracciatura sull'audit log
  • Validazione della capacità massima dei tavoli al momento dell'apertura
  • Modalità "solo bevande" (zero coperti) con esclusione automatica della tariffa coperto
  • Soft-delete di ordini e tavoli per recupero successivo in caso di errore
02
Presa comande e gestione ordini
  • Selezione piatti dal menu con quantità, aggiunzioni a pagamento e rimozioni
  • Sessione di modifica con add/remove/update locale e invio in batch al server
  • Note libere per piatto destinate alla cucina o al bar
  • Cambio piatto con stampa automatica di storno + nuovo piatto
  • Inserimento del separatore "Segue" per organizzare le portate
  • Tasto rapido mobile per aggiungere o togliere "Segue" dopo l'ultimo piatto
  • Modifica del prezzo unitario con motivazione obbligatoria registrata a log
  • Calcolo automatico subtotale = (prezzo + extras) × quantità
22
Coperti e tariffa coperto
  • Numero coperti modificabile in qualsiasi momento del servizio
  • Tariffa coperto per persona configurabile a livello impostazioni
  • Esclusione automatica del coperto in modalità "solo bevande"
  • Inclusione del coperto in totale, fatture e corrispettivi
  • Allocazione coperti per singolo preconto parziale

  • Sconto dedicato al singolo preconto, modificabile o ereditato

  • Chiusura automatica della modale quando tutti i piatti sono stati assegnati

Pagamenti e cassa

  • Bonifico, assegno e altri metodi configurabili nel flusso fattura
  • "Chiusura conto" con apertura cassetto opzionale
  • Fallback manuale del cassetto in caso di mancato collegamento, con notifica Telegram

  • Annullo della transazione in corso prima della conferma

Conformità fiscale italiana

Fatturazione elettronica e corrispettivi

Tutta la conformità fiscale italiana coperta dalla piattaforma. Due provider per i corrispettivi, una sola interfaccia operatore.

05
Fatturazione elettronica B2B
  • Anagrafica clienti privati, aziende e pubbliche amministrazioni
  • Generazione XML Fattura Elettronica conforme alle specifiche AdE
  • Trasmissione SOAP verso il provider Mysond per inoltro al SDI
  • Numerazione progressiva automatica con serie alfanumerica configurabile
  • Più fatture sullo stesso conto con eventuale residuo pagato in altra modalità
  • Riemissione manuale dell'XML in caso di trasmissione fallita
  • Storico fatture emesse con stato di trasmissione e download XML/PDF
06
Corrispettivi elettronici — provider Mysond
Cloud SOAP
  • Emissione automatica del corrispettivo al pagamento contanti o POS
  • Un corrispettivo per ogni preconto pagato (in caso di conto diviso)
  • Esclusione automatica per pagamenti registrati come fattura o "chiusura conto"
  • Tentativo sincrono con timeout configurabile (default 10 secondi)
  • Retry asincrono fino a 3 tentativi con backoff 30s, 2min, 5min
  • Annullo del corrispettivo emesso direttamente dal backoffice
  • Storico completo emissioni e annulli con progressivo SDI e ID transazione
  • Stampa contestuale dello scontrino non fiscale con progressivo
07
Corrispettivi su cassa Ditron RT
NEW · Hardware nativo
  • Emissione dello scontrino fiscale direttamente sulla cassa Ditron RT del locale
  • Comunicazione via TCP/IP con il driver Ditron WinEcrCom già installato
  • Agent .NET 8 sul PC del punto vendita con endpoint HTTP sicuro
  • Pattern Auto-Run Spooler — nessun ActiveX, massima compatibilità
  • Idempotenza per chiave: zero scontrini doppi anche in caso di retry
  • Tabella ditron_receipts con raw command, error file ed elapsed
  • Reparto, tender e label coperto configurabili dal backoffice
  • Modalità fiscale e non-fiscale per test stampa senza scaricare il giornale

Architettura tecnica

Stack moderno, infrastruttura affidabile

Tecnologie aperte, scalabili e dimostrate. Nessun lock-in, nessuna sorpresa.

Backend
PHP 8.3 · framework Laravel 12, code base modulare con servizi dedicati.
Database
MySQL 8.0, oltre 80 migrazioni gestite con versionamento.
Frontend backoffice
Blade templating + Livewire per le componenti dinamiche.
Frontend cassa
JavaScript vanilla con architettura SPA-like, fetch API, gestione stato locale.
UI styling
Tailwind CSS, layout responsive ottimizzato per tablet POS.
Code asincrone
Redis + Supervisor con worker dedicati per stampe, fatture, corrispettivi e backup.
Stampa termica
Protocollo ESC/POS su rete TCP/IP, supporto multi-stampante.
Fattura elettronica
Integrazione SOAP con Mysond, generazione XML conforme SDI.
Corrispettivi Mysond
Trasmissione asincrona ad AdE con retry policy e annulli tracciati.
Corrispettivi Ditron RT NEW
Agent .NET 8 self-contained su Windows, integrazione HTTP con WinEcrCom 3.x. Idempotenza, retry, raw log.
Cassa automatica
Integrazione HTTPS con VNE Self-Cash (apertura, polling, annullo).
Containerizzazione
Docker Compose: PHP-FPM, worker, MySQL, Redis, Nginx, phpMyAdmin.
Autenticazione
Sessioni Laravel backoffice + token operatore con PIN per il frontoffice.
Logging
Canali multipli (default, telegram, corrispettivi) con rotazione giornaliera.
